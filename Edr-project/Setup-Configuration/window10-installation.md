<div align="center"> <h1> Windows-10 Installation</h1> </div>
<h2>overview</h2>
<p>
 Windows installation and initial security configuration of a Windows endpoint for a SOC Analyst L1.
The endpoint serves as a monitoring target for Windows Event Logs, Microsoft Sysmon, and optional Splunk SIEM integration.</p>

<h2>Objective</h2>

<ul>
  <li>Install Windows in a controlled lab environment.</li>
  <li>Configure basic Windows security settings.</li>
  <li>Review Windows Defender and Windows Firewall status.</li>
  <li>Verify Windows Event Log services.</li>
  <li>Prepare the endpoint for Sysmon installation.</li>
  <li>Collect basic system inventory information.</li>
  <li>Prepare Windows logs for security monitoring and investigation.</li>
</ul>

<h2> Tools Used</h2>

<ul>
  <li>Windows 10</li>
  <li>Oracle VirtualBox</li>
  <li>Windows Security</li>
  <li>Windows Defender Firewall</li>
  <li>PowerShell</li>
  <li>Windows Event Viewer</li>
  <li>Microsoft Sysmon</li>
  <li>Splunk Universal Forwarder</li>
</ul>


<h2>Installation Steps</h2>

<ol>
  <li>Obtain official Windows installation media.</li>
  <li>Create a virtual machine or use an authorized physical endpoint.</li>
  <li>Install Windows and complete the initial setup.</li>
  <li>Install available security updates and review security settings.</li>
  <li>Verify Windows Event Logs and prepare the endpoint for monitoring.</li>
</ol>
